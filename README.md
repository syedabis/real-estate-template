# BRIX — Luxury Real Estate & Architectural Developments

A Next.js 16 landing page replicating the **BRIX** real estate advisory website design.

## Features & Implementation

1. **Brand & Typography**:
   - Geometric BRIX polygon logo with architectural facets.
   - Geist Sans font with fine grotesque spacing and contrast.
   - Two-tone editorial copy: bold high-contrast primary thoughts paired with muted secondary descriptions.

2. **Hero Section**:
   - Bold centered headline: **"Buy. Sell. Rent"**.
   - Subtitle: *"Discover your dream home with a trusted advisory partner."*
   - Pill CTA: *"Start your inquiry"*.
   - Luxury stepped terrace penthouse building emerging from ethereal mist and dissolving into pure white.

3. **Trust & Results Section**:
   - ✦ Sparkle emblem with mission statement.
   - Dual-tone text: *"Built on trust and long-term relationships, we guide our clients through every stage of their real estate journey. From first-time buyers to seasoned investors, we deliver results that matter."*
   - Verified stats with clean horizontal dividers:
     - **98%** Client Satisfaction Rate
     - **50+** Prestigious Apartment Sold Monthly
     - **170+** Exclusive Properties in Our Warsaw Portfolio
   - *"More about us"* pill action button.

4. **Showcase Villa**:
   - Wide landscape showcase of the mid-century stone & cedar villa with lush surrounding trees and flagstone terrace.

5. **Why Choose Us ("Your trusted partner in Real Estate")**:
   - Staggered vertical cards:
     - **Technology Solutions**: Diamond wireframe geometry + architectural copy.
     - **Long Term Focus**: Interlocking 4-circle sacred geometry + architectural copy.
     - **Quality Craftsmanship**: Sunburst architectural compass emblem + architectural copy.

6. **Innovative Real Estate Developments**:
   - Grid of 6 luxury architectural residences extracted directly from the design reference.
   - Address labels: `123 Main St, Anytown, USA`
   - Pill badges: `[2 bed, 2 bath]`, `[$4,100]`, `[For Sale]`
   - Interactive Property Detail Modal with specs, descriptions, and private viewing scheduling.
   - *"See all Properties"* pill CTA.

7. **Commercial & Advisory Division (Dark Section)**:
   - Deep charcoal background (`#111111`).
   - Accordion rows with circled numbering `(1)`, `(2)`, `(3)`.
   - **Office Leasing** & **Retail Spaces** with active visual showcase and diagonal arrow buttons.

8. **Interactive Inquiry Modal & Footer**:
   - Full interactive booking / inquiry dialog with property type selector, price range, and instant confirmation.
   - Comprehensive footer with office hubs (*Warsaw • London • Zürich*), confidential newsletter dispatch, and legal links.

## Quick Start

```bash
cd brix-real-estate

# Start development server
npm run dev

# Or build and start production server
npm run build
npm run start
```

The server runs on `http://localhost:3001` (or your configured port).
